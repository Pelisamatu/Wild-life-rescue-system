WILDLIFE SA RESCUE OPERATIONS SYSTEM

This is a NetBeans Java with Ant project for PROG6112 Assignment 2.

OPEN AND RUN
1. Extract the ZIP file.
2. Open NetBeans.
3. Select File > Open Project.
4. Select the WildLifeSARescueSystem folder.
5. Click Run Project, or right-click Main.java and choose Run File.

RUN THE UNIT TESTS
Right-click the project and select Test, or right-click RescueSystemTest.java
and select Test File. All required testing libraries are included in /lib.

FUNCTIONALITY INCLUDED
- Rescue cases stored in an ArrayList
- Create, search, update and display rescue cases
- Injured, orphaned and endangered rescue subclasses
- Rescue-cost and priority calculations
- Abstract class, interface, encapsulation, inheritance, overriding and polymorphism
- Start, complete and rescue-summary operations
- Rescue reports with case totals and total estimated cost
- Controlled rescue-status validation and duplicate-ID prevention
- Clearly documented rescue-priority rules
- Professionally aligned rescue-report columns
- JUnit tests for the required core functionality
